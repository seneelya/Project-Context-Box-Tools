## Реализация — существующий preprocess, без пересборки грамматики

Новый get_codeblock/glsl_source.py; профиль glsl.py подключает его существующим
LangSpec.preprocess. В движках/classify/рендерах нет GLSL-веток, LangSpec handlers
не меняются; оба native wheel остались прежними. Маска bytes→bytes сохраняет длину
и точные позиции всех CR/LF, исходный query/API берётся из physical_lines оригинала.

Лексический view защищает комментарии и строки, включая незавершённые строки с
конечным backslash, block comments и продолжение // через backslash+newline.
[[…]] маскируются лишь вне защищённых областей; вложенные круглые/квадратные скобки
учтены, malformed/незакрытые атрибуты и попытки вложить statements/braces оставляются.
Даже комментарий внутри атрибута остаётся побайтно прежним.

Имена типов и границы числа аргументов — **данные профиля**:
coopmat5, tensorLayoutNV1–2 (ClampMode необязателен), tensorViewNV3–7.
Проверено по первичным спецификациям:
[KHR cooperative matrix](https://github.com/KhronosGroup/GLSL/blob/main/extensions/khr/GLSL_KHR_cooperative_matrix.txt),
[NV cooperative matrix2](https://github.com/KhronosGroup/GLSL/blob/main/extensions/nv/GLSL_NV_cooperative_matrix2.txt).
Маскируется только список после известного имени и перед именем объявления/параметра/
функции либо ( конструктора; member expression исключён. Считаются аргументы верхнего
уровня, скобки выражений сохраняют структуру распознавания. Неоднозначные
несгруппированные сравнения/сдвиги, неизвестные имена, неподходящая arity, незакрытые
списки, braces/semicolon в аргументах остаются сырыми. Обычные a<b/c>d не меняются.

Семантика расширений не компилируется и не валидируется; это структурное чтение.
Подписи карты могут не содержать параметры типов, но извлечённый исходник содержит их
полностью. Строка отдельного атрибута может входить в более широкую filler-полосу
соседних for: синтетический line19 возвращает честную полосу 16–22, код не теряется.
