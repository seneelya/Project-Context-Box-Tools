Plan13 V3 требует: «инварианты CONTRACT #6/#7 на каждой строке». В то же время V1
ограничивает работу существующим preprocess; общая переработка преамбул не предусмотрена.

Проверка всего Vulkan-корпуса обнаружила одинаковое ДО и ПОСЛЕ масок нарушение #6:
Classifier объединяет comment-run через пустую строку и приклеивает весь run к
следующему interface_block. Brace-адресация тоже включает эту строку в диапазон
преамбулы, но ищет её владельца только при попадании в comment_rows (пустых строк
там нет). На `flash_attn_dequant.glsl` карта показывает interface block 1–17,
заголовок/комментарии адресуются тем же 1–17, а пустая строка 14 получает файл 1–146. #7 соблюдён,
query сохраняет текст; #6 в исходном состоянии уже нарушен. Это не создано масками.
