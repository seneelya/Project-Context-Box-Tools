# Plan11 — GLSL в get_codeblock (ТЗ для Gpt-Sol, до конца)

Исполнитель: Gpt-Sol. Поставлено владельцем 2026-11-01. Делается целиком, от колеса до
документации. Claude проверяет результат в конце и коммитит. Возражения `Plan11__KICKBACK.md`
(K1 → D9 и шаг 4; K2 → D7/D8, шаг 2 и шаг 4) приняты и внесены сюда — исполнять по этому файлу.
Временные данные, кэши, сборки — только на T: (TEMP/TMP/PIP_CACHE_DIR явно, без `__pycache__` на C:).

Предыстория: `done/Plan10__glsl-grammar-wheel.md` (колесо), `__dev/review/GLSL_PROBE.md` (выбор
грамматики), `__dev/review/GLSL_BUILD.md` (сборка и найденный дефект runtime).

## Решения (приняты, не переоткрывать)

**D1. Plan10 закрывается принятием колеса `1.0.0+capsule1`.** Строгая приёмка Plan10 провалилась
не из-за колеса, а из-за дефекта py-tree-sitter 0.26.0: getters `Point.row`/`Point.column`
возвращают borrowed reference (`PyTuple_GetItem`) → счётчик ссылок уходит в минус → плавающие
access violation. Claude проверил независимо: после чтения `p.row` refcount числа уменьшается на 1.
Индексный доступ (`point[0]`) корректен. Колесо с индексным доступом — 480/480, совпадение с
baseline 0.25.2. Новее 0.26.0 на PyPI нет. Критерий приёмки Plan10 меняется на индексный.

**D2. Правило для всего кода tools: точки tree-sitter читать ТОЛЬКО по индексу**
(`start_point[0]`, `end_point[1]`), никогда `.row`/`.column`. Дефект не зависит от языка: любой
`.row` на большом файле (числа > 256, вне кеша малых целых) — мина. Сейчас в tools, hermes-filetools
и memohood таких мест нет (Claude проверил поиском) — правило закрепляет это тестом.

**D3. Грамматика — `glsl-spec`** (Caellian, коммит `3a00d49`). Старая `glsl` 0.2.0 не берётся.

**D4. Расширения → GLSL:** `.glsl`, `.vert`, `.frag`, `.geom`, `.comp`, `.tesc`, `.tese`, `.vs`, `.fs`.
`.fs` — это ещё и F#, но F# get_codeblock не поддерживает, конфликта нет. Если F# появится — решать
в единственной карте `reader/reader.py::_LANG_MAP`. Записать это в `__dev/DECISIONS.md`.

**D5. Подключение — по Рецепту A** (`get_codeblock/reader/CONTRACT.md`): язык = данные
(профиль + строки в реестрах), НЕ ветка `if lang == 'glsl'` в движке/рендере/classify.

**D6. Ошибки препроцессора не скрывать и не выбирать одну ветку.** `#ifdef … } else #endif …`
даёт ERROR/MISSING — это честно. Обязательны инварианты CONTRACT: #7 (выданный блок содержит
строку), #6 (карта и адресация согласованы). Ни одна строка файла не должна «потеряться». Если в
районе ошибки точной вложенности нет — допустим более крупный честный блок (до функции/файла),
недопустимы неверный блок и падение.

**D7. Без рабочей грамматики — чистый отказ, не traceback** (уточнено по KICKBACK K2). Три случая,
все с кодом ошибки и без трейсбека:
- модуль не установлен (например, Python Hermes) → сообщение с командой установки ИМЕННО
  поставляемого колеса (абсолютный путь, вычисленный от расположения `env_check.py`, т. е. верный
  из любого cwd) — НЕ `pip install tree-sitter-glsl-spec` (PyPI 1.0.0 на 0.26 не грузится);
- установлен старый upstream 1.0.0 (`language()` отдаёт `int`, не capsule) → «установлена
  несовместимая сборка» + та же команда с `--force-reinstall --no-deps`. Без ctypes-моста;
- платформа не `win_amd64` → честно: «готового колеса для этой платформы нет, сборка —
  `wheels/README.md`», без заведомо непригодной команды.

Механизм — данные, не `if lang == 'glsl'`: у записи языка в `env_check` необязательные поля
«локальный артефакт установки» (путь от корня tools + платформа) и «проверка загрузки» (общая:
`language()` должен вернуть capsule). Языки без этих полей ведут себя как раньше.

**D8. Колесо распространяется файлом** `wheels/tree_sitter_glsl_spec-1.0.0+capsule1-cp310-abi3-win_amd64.whl`
в репо tools, ставится `pip install --force-reinstall --no-deps <путь>`. Внутрь пакета
get_codeblock бинарник НЕ кладём. В `get_codeblock/requirements.txt` колесо НЕ вписывать (путь к
Windows-колесу сломал бы установку на других платформах и зависит от cwd) — там только комментарий
со ссылкой на `wheels/README.md`; источник правды для установки — запись в `env_check` (D7).

**D9. Приёмка диапазонов — по правилам публичного блока** (KICKBACK K1). Сырой
`function_definition` и публичный блок get_codeblock — разные вещи: публичный включает приклеенную
преамбулу комментариев (CONTRACT, инвариант #6) и может расширяться авто-эскалацией без `--force`.
Правила get_codeblock ради GLSL не меняются.

## Ограничения

- Рабочий tree-sitter 0.26.0 не менять. Python Hermes, `Y:/Hermess/**` — не трогать, колесо туда
  не ставить (решает владелица). Шлюз Hermes не перезапускать.
- Шейдеры PlanetWeather — только чтение. Фикстуры для тестов — копии/вырезки в `test/`.
- Общие `LangSpec` в `handlers/` не менять (инвариант #5). Новые поля/механизмы — только
  необязательные, со значением по умолчанию, не меняющим поведение других языков.
- Если для GLSL нужен новый шов в движке (см. шаг 3) — общий, данными, с описанием в CONTRACT; и
  весь регресс других языков обязан остаться прежним.
- Не коммитить. Не деплоить (`deploy_hq.py`, `deploy.ps1`) — только по слову владелицы.
- Читать код get_codeblock'ом (`--outline` → `--line N --query` / `--name X`), не целиком.

### 2. Профиль и обвязка (Рецепт A)
Все касания из CONTRACT «Обвязка»:

  проверка загрузки), `get_codeblock/requirements.txt` — только комментарий-ссылка (D8).

### 3. Форма дерева glsl-spec (главная работа)
Отличия от C, из GLSL_PROBE.md: у `function_definition` нет поля `body` — тело прямым
`compound_statement`; внутри — лишний слой `statement_list`; имена параметров/переменных — через
`declarator_list`/`declarator` и поле `name`.
- Без раскрытия `statement_list` весь код функции — одна полоса (первая функция: 8–10 вместо
  `expression_statement` 8–9 + `return_statement` 10). Нужно раскрытие.
- Сначала выяснить, покрывается ли это существующими наборами LangSpec (`transparent_parents`,
  `body_types`, `scope_body` и т. п.). Если нет — один общий необязательный шов (например, набор
  «прозрачных обёрток», которые движок раскрывает), описанный в CONTRACT. `FlatNode` из
  `glsl_adapter_probe.py` — образец идеи, не готовый код.
- Имена для `--name` и подписей карты: функции, глобальные объявления (`uniform`/`in`/`out`/
  `const`), структуры; несколько имён в одной декларации (`float a, b;`) — как R06 для C/C++.
- `#define` не должен захватывать начало следующей строки (замечено в пробе).
- `layout(location = …)`, `#version` — не ломают карту.
