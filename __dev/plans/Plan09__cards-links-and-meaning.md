## Шаг 0 — баг: мусорные флаги в Build facts · ✅

`UINTPTR_MAX == 0xFFFFFFFF` даёт «флаги» `L`, `xFFFFFFFF` (`stamp_langs/cpp.py::_flags` режет
идентификаторы из чисел). Числовые литералы (`0x…`, `…L/U`) — не флаги. Тест.

## Шаг 1 — кэш сканов `__HQ/tools/_cache/<root>-<hash>/` · подготовка ✅ (`.gitignore`, deploy exclude)

- Слой в `find_code_usage/cpp_includes.py` (Tree): загрузка → сверка отпечатков (`git ls-files -s`
  + `git status`; без git — mtime+size) → доскан изменённых → запись. Отпечаток конфига `CPP_*` и
  версия тула в шапке кэша → полный пересчёт при смене.
- Второй потребитель: имена, встречающиеся в файле (для `cpp_handler` — потребители символов).
- `.gitignore` tools-репо: `_cache/`; `deploy_hq._TOOLS_EXCLUDE_PARTS` += `_cache`.
- Тесты: изменить файл → пересканирован ровно он; удалить/добавить; смена конфига → пересчёт.

## Шаг 3 — форма карточки заголовка «API: in source» (`CARD_FORMAT` 1.3.0)

- `CARD_FORMAT`: маркер `API_IN_SOURCE`, подсекция `### What each family is for`.
- Хук модуля языка (контракт `stamp_langs`, ПОПРАВКА 2): язык сам решает форму Public API для
  файла (C/C++-заголовок → «in source» + таблица семейств); штемпель рендерит, не решая за язык.
- Merge: проза семейств по имени (механика `_parse_why_section`); исчезнувшее семейство → Salvage.
- `validate_cards`: Public API с маркером валиден без `####`; названный исходник обязан
  существовать; колонки таблицы семейств — фиксированы.
- Тесты: свежий штамп, merge с прозой семейства, переименованное семейство → Salvage, валидатор.

## Шаг 4 — граф: рёбра из исходников для файлов без карточек

`graph_from_cards`: для C/C++-корня — узлы-файлы без карточек из кэша (помечены «no card»),
их рёбра и условия — из скана. `--file` показывает полный `used-by`. Флаг, чтобы выключить
(`--cards-only`) — старое поведение. Тесты: зона из 4 карточек, `used-by` видит файлы вне зоны.
