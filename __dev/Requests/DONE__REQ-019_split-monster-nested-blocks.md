# REQ-019 — split_monster: перенос вложенных блоков (метод, внутренний блок) в существующий файл

Найдено: владелица, 2026-11-17. Исполнитель: Claude (Opus), в этой же сессии.

## Что было

`--split LINE` для кода всегда брал блок 1-го уровня: строка внутри метода превращалась в весь
класс, без предупреждения. Вручную `cut(..., level=2)` выделял метод, но его текст с отступом
вставал на верхний уровень цели — файл не парсился, `verify` откатывал. Перенести один метод
было нельзя.

## Что просим (решения владелицы)

1. **По уровню** вырезать тот блок, который показывает `get_codeblock --line N --level L`.
2. **Связывания нет.** Сложное встраивание не сделать: тул убирает блок в одном файле и
   «проявляет» его в другом. Гарантирует только механику — ничего не потеряно/не выдумано,
   скобки и отступы целы. Импорты, имена, `self`, замыкания — работа агента; тул прямо об этом
   предупреждает. Поведение верхнего уровня (импорты, граф, реэкспорт) не меняется.
3. **Отступ** сдвигает тул, чтобы агенту не переписывать блок и не писать скрипт. Решение о
   сдвиге — агента: функция в сгенерированном скрипте (`place(...)`), тул лишь предлагает число.
4. **Файл перестал парситься** (класс без единственного метода и т. п.) — НЕ откат: разрез
   остаётся, тул называет файл/строку, агент правит сам (`pass`) или `--undo`.
5. **Только второй проход, только в существующий файл.** Номер строки в файле, который создаётся
   в этом же запуске, неизвестен. Запуск с вложенными блоками — отдельный проход: все `--split`
   в нём вложенные, все цели уже существуют; иначе отказ с подсказкой («сначала разрежь верхний
   уровень»).
6. **Место — якорь-блок в цели, не голая строка.** Агент смотрит `get_codeblock --outline` цели
   и называет блок его стартовой строкой из карты:
   - `--after N` / `--before N` — сразу после / перед блоком цели, что начинается на N (строка
     внутри блока = самый внутренний блок, как последняя ступень лестницы `--line`);
   - `--into N` — последним ребёнком этого блока (например, последним методом класса).
   Отступ берётся у якоря (`after`/`before` — как у него, `into` — как у его детей), виден в
   `place()` и правится там. Голый `--at N` (вставить перед строкой N) — убрать.
