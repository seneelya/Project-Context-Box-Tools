# REQ-008 — `make_interface_card.py --all` не уважает `CONFIG__TOOLS.BLACKLIST_DIRS`

## Почему проверяла

Готовилась проштамповать карточки для `desktop/src/*.js` в проекте hermes-filetools (19 файлов).
Перед тем как запускать `--all --language js` (стемпит вообще всё под `--project-root` по
языку), захотела убедиться, что оно не заденет `desktop/compiled/plugin.js` — это генерируемый
esbuild-бандл, на который в проекте сознательно нет карточки (папка `compiled` заведена в
`BLACKLIST_DIRS` в `CONFIG__TOOLS.py` именно ради этого — другие тулы её уже уважают).

## Что нашла

`grep -n "BLACKLIST_DIRS\|SKIP_DIRS\|skip_dirs\|compiled" make_interface_card.py` — ноль
совпадений. Инструмент `BLACKLIST_DIRS` из `CONFIG__TOOLS.py` вообще не импортирует. У `--all`
свой отдельный захардкоженный пропуск-лист (`.git`/`__pycache__`/`__map`/`__HQ`/`.venv`/
`node_modules` + `CONFIG__TOOLS.TEST_DIRS`) — `BLACKLIST_DIRS` в этот список не попадает.

Практический эффект: `--all` проштамповал бы `desktop/compiled/plugin.js` наравне с реальными
исходниками — карточку на сгенерированный файл, которую потом придётся руками чистить/игнорировать.

## Что сделала вместо этого (обошла проблему, не чинила инструмент)

Не стала рисковать — проштамповала все 19 файлов `desktop/src/**/*.js` по отдельности, явно
указывая путь каждого (не через `--all`). `compiled/` в этот список просто не попал.

## Что, скорее всего, нужно сделать

`--all` в `make_interface_card.py` должен читать и уважать `CONFIG__TOOLS.BLACKLIST_DIRS` —
так же, как это уже делают другие тулы в `__HQ/tools/` (see `CONFIG__TOOLS.py`'s own
docstring — `BLACKLIST_DIRS` описан как общий контракт для "file scanning" тулов, а
`make_interface_card.py --all` это тоже сканирование файлов по дереву). Иначе любой проект, где
завёл `BLACKLIST_DIRS` под конкретную папку с генерируемым кодом, обязан либо помнить об этом
руками при каждом `--all`, либо потом чистить лишние карточки.

Возможно стоит также свести местный пропуск-лист (`.git`/`__pycache__`/`__map`/`__HQ`/`.venv`/
`node_modules`) и `BLACKLIST_DIRS` в один источник правды, если у других тулов в `__HQ/tools/`
похожая ситуация — не проверяла остальные, это только по `make_interface_card.py`.
