# REQ-016 — C/C++: проза карточки из шапки `.h` и комментариев у `#include`, карточка — целиком штамп

## Зачем это нужно (контекст извне)

dvOrbital sim (ветка `gfx`, 2026-10-23): мелкие C++ файлы, карточки на них больше самих исходников.
Пример — `src/probe/ui/help_line.h` (13 строк) и `help_line.cpp` (54): карточки
`__HQ/__map/src/probe/ui/help_line.h.md` (46) и `help_line.cpp.md` (43) — 97 строк описания на
67 строк кода.

Что в такой карточке:
1. **Факты** — выводятся из исходника: объявления, `included by`, пара `.h ↔ .cpp`, внешние импорты.
   Их уже ставит `make_interface_card`. А `graph_from_cards --file` для C/C++ сам сканирует
   `#include`: файлы без карточек входят в срез узлами `(no card)` со связями из исходника.
2. **Проза** — строка «что это», `## How it works`, «зачем каждый импорт». В C++ она почти
   всегда уже есть в шапке `.h` (в `help_line.h` — дословно то же, что в карточке).

Итог: для C/C++ проза карточки дублирует заголовок, а пишется и устаревает руками.

## Чего хочется

`make_interface_card` для C/C++ берёт прозу из исходника, карточка становится целиком штампом:

- **Шапка файла** — первый блок комментариев после `#pragma once` / include guard: первая строка
  (или первое предложение) → строка-сводка под H1; остаток → `## How it works`.
- **Комментарий у `#include` проекта** (в той же строке `// …` или строкой выше) → строка
  «Why these imports are used» для этого импорта.
- **`.cpp` с парой `.h`** — сводка и How it works берутся из `.h` (или пишется «see pair»), своей
  прозы не требуется.
- Нет шапки / нет комментария — как сейчас: строка `<Agent: …>`.
- `## Runtime seams` (REQ-010) остаётся ручной: в синтаксисе этих связей нет.

Следствие: перештамповка `--stale` обновляет и прозу — устаревшей карточки при свежем
заголовке не бывает.

## Как проверить

- `make_interface_card.py src/probe/ui/help_line.h` — сводка и How it works совпадают с шапкой
  файла, `<Agent:` в выводе нет.
- Файл с комментариями у `#include` — строки «why» заполнены; импорт без комментария — `<Agent:`.
- `validate_cards` принимает такую карточку; `graph_from_cards --file help_line.h` показывает
  сводку из шапки.
