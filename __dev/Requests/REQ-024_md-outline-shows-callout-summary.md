# REQ-024 — Markdown: `--outline` показывает callout сразу под заголовком (сводку секции)

## Зачем это нужно (контекст извне)

contact_lab (`T:\Agents\contact_lab\__HQ\docs`, 25 Nov 2026): документы разрезаны и озаглавлены по
`Guide__Outline`, чтобы читать их через `get_codeblock --outline --level 3` и брать одну секцию через
`--query`. Но в outline md видны только заголовки, а заголовок короткий: `### kLawCapture` или
`### The reach (Part 86)`, и что внутри, по нему не понять.

В коде этой проблемы нет: outline приклеивает к блоку его комментарий и показывает начало комментария:

```
//. [31-31] // Fmin of the gate: the curve's thrust_min, else kGateFloor…
```

У md такого «комментария секции» нет. Угадывать его по первой фразе тела ненадёжно: там бывают таблица
(`| Law | No. | What it does |`), блок кода или обрывок вроде «(`src/route_escape.cpp`).».

Решение владелицы: автор явно пишет сводку callout-блоком сразу под заголовком, а outline её показывает.

## Чего хочется

Только для Markdown (`.md`); код, YAML и прочие форматы не меняются.

- **Что считается сводкой:** первая непустая строка после заголовка начинается с callout с типом,
  `> [!<type>]` (любой тип: `info`, `note`, `summary`, `tldr`, `warning`…, регистр любой). Обычная цитата
  `>` без `[!type]` сводкой не считается.
- **Берётся блок целиком:** все строки callout до его конца (по правилам цитаты: подряд идущие строки
  с `>`, ленивые продолжения тоже), включая текст в той же строке после `[!type]`. Маркеры `>` и
  `[!type]` снимаются, строки склеиваются через пробел, пробелы сжимаются.
- **Показ:** в строке заголовка в outline — после текста заголовка, первые **200 символов** сводки
  (длиннее — обрезать с `…`). Тип callout показать коротко в начале, например `[info]`.

  ```
  <!--     3 [166-178] `kLawCapture` · [info] The capture law: brakes about the periapsis, turns the plane at the apoapsis; CPU only. -->
  ```

- **Без callout** — строка заголовка как сейчас, ничего не добавляется (никаких догадок по телу).
- `--query`, `--level` и границы блоков не меняются: callout остаётся частью тела секции (`~content`);
  REQ-014 (тело секции — один блок) это не затрагивает.
- YAML frontmatter (`meta:`) — как сейчас.

## Как проверить

- md с `### A` → пустая строка → `> [!info] one line` → outline показывает `[info] one line`.
- Многострочный callout (`> [!note]`, потом `> line 2`, `> line 3`) → склеено в одну строку; > 200
  символов → обрезано с `…`.
- Callout не первым после заголовка (сначала абзац текста) → ничего не показывается.
- Обычная цитата `> text` без `[!type]` сразу под заголовком (как во вступлении `START.md`) → ничего не
  показывается.
- Заголовок, за которым сразу идёт подзаголовок, → как сейчас.
- `--query` на строке секции возвращает тело вместе с callout, как раньше.
- Код (`.py`, `.cpp`) — вывод outline байт в байт прежний.

## Что изменится у пользователей

- `Guide__Outline` (шаблон ProjectStarter): добавить правило письма — под каждым содержательным `##` /
  `###` одна строка callout с сутью секции одной фразой (`> [!info] ...`), без деталей; outline тогда
  читается как оглавление с аннотациями.
