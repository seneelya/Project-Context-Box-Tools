# REQ-017 — пустая строка внутри комментария-преамбулы адресуется как весь файл (инвариант #6)

Найдено: Gpt-Sol при Plan13 (Vulkan-шейдеры, 2026-11-01), подтверждено Claude на C++ и TS.
Дефект ПРЕДСУЩЕСТВУЮЩИЙ и общий для brace-движка, не GLSL. Сырьё Sol:
`T:/AgentsWork/glsl-wheel-plan10/plan13/` (`preamble-gap.glsl`), разбор — `__dev/plans/Plan13__KICKBACK.md`.

## Воспроизведение (синтетика)

```cpp
// Header

// Details
struct Data { float x; };
void f() {}
```

- `--outline`: `[1-4] struct Data  // Header …` — комментарии через пустую строку приклеены (так и
  требует CONTRACT «Конвенция НАЧАЛА»: пустые строки склейку НЕ рвут).
- `--line 4` → блок 1–4. Верно.
- `--line 2` (пустая строка внутри преамбулы) → `<file>` 1–5. **Неверно:** карта относит строку 2 к
  блоку 1–4, адресация — к файлу. Нарушен #6 (карта и адресация согласованы). #7 соблюдён.

То же на `.ts` (`function a()`), `.glsl` (interface block). На 185 Vulkan-шейдерах — 5 строк.

## Причина (по Sol)

Classifier склеивает comment-run через пустую строку и отдаёт весь run следующему блоку. Brace-
адресация включает эту строку в диапазон преамбулы, но владельца строки ищет только при попадании
в `comment_rows` — пустых строк там нет.

## Что сделать

- Одно общее правило без языковых веток: пустая строка МЕЖДУ строками комментариев одной преамбулы
  принадлежит владельцу преамбулы (как в карте). Пустая строка ДО первого комментария или ПОСЛЕ
  блока — по-прежнему не его.
- Проверить ТРИ места из «Конвенции НАЧАЛА» (адресация `_preamble_start`, outline `classify`/`pending`,
  focus `_focus_head`) — согласованы.
- Тест-фикстуры: C++, TS, C#, GLSL (синтетика) — строка-пробел внутри преамбулы → блок; пробел перед
  преамбулой → не блок.
- Регресс: всё из `__dev/CONTEXT_RESTORE.md` + old/new сравнение вывода (`--outline`, `--line` по
  всем строкам) на test/ фикстурах и зоне llama.cpp_mix: меняться должны ТОЛЬКО такие пустые строки.
  Python (`python_handler.collect_preamble`) — проверить, есть ли там то же; если есть — тем же правилом.
- `sweep_invariants.py`: научить ловить этот класс (#6 на пустых строках преамбулы), чтобы не вернулся.
