# Plan: get_codeblock

## Структура проекта
```
get_codeblock/
├── __init__.py          # пустой, для импорта
├── core.py              # CLI аргументы + вызов обработчика
└── handlers/
    ├── __init__.py      # registry: get_handler(language)
    └── python_handler.py  # первый — по отступам
```

## Шаг 1: Python handler (по отступам)

### Алгоритм поиска блока строки N:
1. Прочитать файл полностью
2. Найти строку N, определить её отступ
3. Идти вверх по строкам:
   - Если отступ < текущего → нашли родительский блок
   - Если отступ >= текущего → продолжаем внутри того же блока
4. Запомнить (from_line, to_line) каждого предка
5. Идти вниз по строкам:
   - Если отступ > текущего → это дочерний блок
   - Если отступ <= текущего → вышли из блока

### Уровни:
- Уровень 0 = глобальный код (отступ 0)
- Уровень 1 = первый уровень вложенности (def/class/if/for/while/try/etc.)
- Уровень N = N-й вложенный блок

### Вывод без --query:
```
<level> <from_line> <to_line>
```

### Вывод с --query:
- Текст блока из файла (байт-в-байт, от from_line до to_line)

## Шаг 2: TS/JS handler (по фигурным скобкам)

### Алгоритм:
1. Считать файл
2. Найти строку N
3. Идти вверх по строкам, считать открытые/закрытые `{`
4. При балансе 0 → нашли начало блока
5. Аналогично вниз для конца блока

## Шаг 3: C# handler (по фигурным скобкам + #region)

### Алгоритм:
- Тот же, что TS, плюс поддержка `#region ... #endregion` как блоков
