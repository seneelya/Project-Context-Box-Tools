# get_codeblock — Vision Contract

## Назначение
Возвращает осмысленный законченный блок кода, содержащий заданную строку файла, для LLM-агентов.

## Принцип работы

### Без `--query` (только `--level N`)
Формат вывода: `<level> <from_line> <to_line>` — всегда 3 числа.

| level | Описание |
|-------|----------|
| 0 | Реальный уровень строки + границы блока текущей строки |
| 1 | Границы блока уровня 1 (самый верхний, содержащий строку) |
| 2 | Границы блока уровня 2 |
| -1 | Родительский блок (на уровень выше) |
| -N | N-й предок по иерархии |

### С `--query N`
Вывод: **текст блока** из файла (байт-в-байт, как будто читаешь файл от `from_line` до `to_line`).

| query | Описание |
|-------|----------|
| 1 | Текст самого верхнего блока, содержащего строку |
| 2 | Текст следующего по вложенности блока |
| N > real_level | Вернёт текст блока реального уровня строки (не глубже) |
| 0 | Текст текущего блока (где строка) |
| -1 | Текст родительского блока |
| -2 | Текст дедушкиного блока |

### Иерархия уровней (пример)
```python
def main():                # ← уровень 1, query=1 вернёт текст этого блока
    if x > 0:              # ← уровень 2, query=2 вернёт текст этого блока
        for i in range(3): # ← уровень 3, query=3 вернёт текст этого блока
            print(i)       # ← строка на уровне 3 (внутри for), level=0=3
```

## Обработка блоков
- **Python**: по отступам (пробелы/табы) — блок = область с увеличенным отступом
- **TS/JS/C#**: по фигурным скобкам `{}`
- Считаются **ВСЕ** блоки: функции, классы, методы, if, for, while, try/catch, with, regions и т.д.
- Без `--query` → границы `[from_line, to_line]`
- С `--query` → текст блока из файла (байт-в-байт)
