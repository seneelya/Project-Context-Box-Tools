## Инструкции по тестированию

### Базовые тесты (Python)

1. **Файл без вложенностей** — строка на глобальном уровне → `level=0`, `query=0` вернёт текст файла
2. **Вложенность 1 уровень** — строка внутри функции/класса → `level=0=1`, `query=1` вернёт текст функции
3. **Вложенность 2+ уровни** — строка в `if` внутри `def` → `level=0=2`, `query=1` вернёт def, `query=2` вернёт if
4. **Отрицательные уровни** — `level=-1` вернёт границы родительского блока
5. **Query > реального уровня** — `query=5` когда строка на уровне 3 → вернёт текст блока уровня 3

### Тесты с большими файлами (hermes-agent-src)
- Проверить производительность на файлах 1000+ строк
- Проверить корректность на файлах без вложенностей (только глобальный код)

### TypeScript (ts-prune)
- Скопировать паттерн Python для TS: блоки по `{}`
- Проверить функции, классы, if/for/while

### C# (CoreSharp → test_SWARM_SRC → test_Unity)
- Скопировать паттерн TS (скобки `{}`)
- Дополнительно: `#region ... #endregion`
- Проверить на больших файлах Unity/SWARM

## Формат вывода для тестов

### Без `--query`
```
<level> <from_line> <to_line>
```
Пример: `0 10 25` — строка на уровне 0, блок от строки 10 до 25

### С `--query`
Выводится только текст блока (байт-в-байт из файла).
