# PLAN — консолидация тулов (план A) + восстановление контекста

> Небольшой план для переезда и как точка восстановления. Цель: **`t:\AgentsWork\tools\`
> = единый dev-дом утилит; ProjectStarter = потребитель готового.** Тут пишем/чиним →
> оттуда переезжает в `ProjectStarter/__HQ/tools/`.

## Где мы сейчас
Два дома утилит:
- **этот репо** (`tools/`, git `master`): `codebase_import_search`, `get_codeblock` — доведены,
  протестированы (golden-харнесс `test/check.py`, 49 проверок), доки синхронизированы.
- **ProjectStarter `__HQ/tools/`**: `card_format`, `rebuild_graph`, `bundle`, `validate_cards`,
  `check_freshness`, `mask_replace`, `py_api`.

Три логических слоя:
- **анализ исходника:** `import_search`, `get_codeblock` (+ `py_api`);
- **карта на карточках:** `card_format`, `rebuild_graph`, `bundle`, `validate_cards`, `check_freshness`;
- **обслуживание:** `mask_replace`.

## Целевая форма
Один `tools/` с **одним `TOOLS.md`**, сгруппированным по трём слоям выше; один доков-контур
(`Catalog→TLDR→--help→Run`); один `__HQ` с Vision/HowTo. Границы слоёв явны в доках.

## Шаги (по порядку, каждый под зелёный `check.py`)
1. **Стянуть тулы ProjectStarter → сюда** (в `tools/`, сохранить `__`-структуру).
2. **Починить само-локализацию:** тулы ProjectStarter ищут `parents[2]/__map` от своего места —
   при переезде выправить пути/дефолты (иначе `rebuild_graph`/`validate_cards`/`check_freshness`
   потеряют `__map`).
3. **Снять дубль `py_api` ⟷ `--outline`:** сделать `py_api` (ast) **AST-бэкендом Python-outline**
   (точность заголовков даром), а не отдельным ответом на тот же вопрос. Одна концепция.
4. **Единый `TOOLS.md`** (3 слоя) + сверить доков-контур каждого тула.
5. **Вписать плейбук в роли/гайды** (это и делает тулы «удобными» для ЛЛМ):
   большой файл → `--outline`→`--query`; меняю символ → `import_search` downstream + `get_codeblock`;
   зависимости → `--incoming`; пишу карточку → `import_search` + `--outline`.
6. **Позже:** отлаженный набор → в `ProjectStarter/__HQ/tools/`.

## Решения / инварианты (не релитигировать)
- `__`-маркер меты (`__HQ`/`__map`); пути в выводе всегда `/`.
- **Граница:** тулы-исходника = фактодобытчики; «кто кого вызывает» и карта проекта = **карточный
  слой** (`rebuild_graph` над карточками). Не растить тулы в графовую систему (антимонстр).
- Уровни: `1 + объемлющие тела`, корень=1, `0` не глубина (см. `Vision01__get_codeblock.md`).
- Через каждый шаг переезда — `py test/check.py` зелёный.
